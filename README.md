# A股趋势选股器

基于对数线性回归分析的A股选股工具，支持趋势扫描和多情景DCF估值。覆盖沪深主板、创业板、港股及主流ETF。

## 功能

### 价值筛选
- 按市值筛选A股（默认 ≥ 300 亿）
- 计算 **10年 / 5年 / 3年对数线性回归**（年化收益率 + R²）
- 基于回归残差 P10/P90 的**价格通道**（止损/止盈参考价）
- **悲观混合预测 PE**：对分析师一致预期 EPS 做几何平均降权，削弱乐观偏差
- **两阶段 DCF 合理 PE**，三种终局增速情景（悲观 0%、基准 = 无风险利率、温和 3%）
- 金融股（银行/保险/证券）使用 **P/B 估值**（Gordon 增长模型）
- 周期股（煤炭/金属/石油/钢铁）使用**历史 PE 分位**估值
- **EPS/PE 收益分解**：将 10 年和 5 年的价格涨幅拆分为盈利增长与估值扩张两部分

### 趋势扫描
- 对周收盘价做对数线性回归（个股取 10 周，ETF 取 7 周）
- 输出斜率（周度年化）、R² 及残差标准差 σ_res（趋势稳定性）
- 20 周涨幅用于超买识别
- 覆盖 A 股、港股主板及 20+ 大宗商品/行业/宽基 ETF
- 前端筛选后按需加载 52 周分位通道

### 组合分析
- 自定义股票列表的批量估值
- 每只个股输出回归统计 + 一致预期 EPS + DCF 情景

### 个股详情
- 后复权价格走势图，叠加 10/5/3 年回归线及通道
- 10 年 PE TTM 历史，标注当前分位及亏损期阴影
- 分析师一致预期 EPS 表（实际值 + 3 年预测 + 前瞻 PE）
- 分时/日线/周线切换

### 移动端 PWA
- `/mobile` 提供响应式移动端布局
- 通过 `/manifest.json` 支持添加到主屏幕

## 快速开始

```bash
pip install -r requirements.txt
python app.py
```

浏览器访问 `http://localhost:5000`。

**依赖要求**：Python 3.11+，详见 [requirements.txt](requirements.txt)（`flask`、`requests`、`numpy`、`baostock`）。

## 估值模型说明

**悲观 EPS 混合**——用最近一期实际 EPS（A）对分析师预测值做几何平均降权：

```
B* = √(A·B)    C* = ∛(A·B·C)    D* = ∜(A·B·C·D)
悲观预测 PE = 现价 × 4 / (A + B* + C* + D*)
```

**两阶段 DCF 合理 PE**（普通个股）：

```
PE_合理 = Σ(i=1..3) E*_i/E0 / (1+r)^i  +  E*_3/E0 · (1+g_t) / [(r−g_t)·(1+r)³]
r = 无风险利率 + 5%（股权风险溢价）
```

**终局增速情景**：

| 情景 | 终局增速 g_t |
|------|------------|
| 悲观终局 | 0% |
| 基准终局 | 10 年期国债收益率 |
| 温和终局 | 3% |

**金融股**（银行/保险/证券/多元金融）采用 P/B Gordon 增长模型：`PB_合理 = ROE / (r − g_t)`，股权风险溢价取 8%。

**周期股**（煤炭/金属/石油/钢铁等）跳过 DCF，改用 10 年历史 PE 的 P25 / 中位数 / P75 乘以最近实际 EPS 计算参考价。
